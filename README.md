# TapeMaster Gate

TapeMaster Gate 是面向声音档案数字化团队的本地浏览器工作台。它把磁带载体建档、采集前检、参数化采集、自动与人工质检、修复版本复核、母版清单冻结和交付凭据验证串成一条可审计的质量放行流程。

系统只使用 Go 标准库，不需要 Node 构建链或外部服务。事实记录保存在本地链式 JSON 事件日志中；每个提交帧包含递增序号、前序摘要与校验和，启动时会验证完整事件链并重建内存投影。写操作同时使用 `expectedVersion` 乐观并发控制和 `idempotencyKey` 幂等保护。

## 状态流转

作业依次经过：`draft` → `ready` → `capturing` / `remediation` → `pending_approval` → `frozen` → `certified`。

- `draft`：登记载体、采集规格与保存状况；逐盘记录清洁、外观、播放兼容性、处置说明、检查人和检查时间，再与作业级设备校准、存储空间共同计算采集就绪。任一载体阻断都会留在建档状态并明确显示原因。
- `capturing` / `remediation`：登记带 SHA-256 的采集版本，在写入前校验作业内有效摘要和规范化母版文件名唯一性。详情按载体显示完整版本谱系、作废原因、整改说明、规则复跑结果和当前母版；质量发现以开放、待复核、已关闭、被驳回组成可筛选队列，被驳回事项可随下一替代版本进入新的整改轮次。
- `pending_approval`：要求每盘载体都有有效采集，且所有严重发现均已关闭。
- `frozen`：负责人先通过 `GET /api/v1/jobs/{jobId}/manifest/preview` 只读核对逐盘母版、参数、覆盖缺口、严重发现、拟定修订号和整体摘要；冻结请求必须回传 `previewVersion` 与 `previewDigest`，确保实际冻结内容和预检完全一致。冻结后拒绝后续采集或整改变更。
- `certified`：签发唯一交付凭据，可用凭据编号与校验码公开核验清单摘要。

## 构建

```bash
go build ./cmd/server
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`，数据写入 `.tapemaster-data`：

```bash
go run ./cmd/server
```

可显式指定其他回环地址与数据目录：

```bash
go run ./cmd/server -addr=127.0.0.1:19181 -data=./runtime-data
```

未传入 `-addr` 时也可通过 `PORT` 指定端口，服务会绑定 `127.0.0.1:<PORT>`。服务拒绝非回环 IP 和低于 `1024` 的端口。启动后访问 `http://127.0.0.1:19081/` 使用响应式工作台，同源 JSON API 位于 `/api/v1/`。

## 测试与自检

运行全部单元和流程回归测试：

```bash
go test ./...
```

运行有界端到端自检。该命令会在实际配置的监听地址启动 HTTP 服务，通过首页与 JSON API 完成建档、前检、采集、送审、冻结、发证、验证和审计检查，然后自动退出：

```bash
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

## 数据与故障诊断

默认数据目录包含 `events.jsonl` 和 `checkpoint.json`。`events.jsonl` 是事实来源，不应手工编辑；`checkpoint.json` 通过临时文件同步后原子替换，用于保存投影和幂等结果。启动时若发现事件序号断裂、摘要链不一致、校验和错误、引用关系损坏或截断尾帧，服务会输出明确错误并停止启动，避免静默丢弃已确认事件。
